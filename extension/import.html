    2 Passwords

    1. In your other browser, open its password settings and choose Export passwords. It saves a .csv file.
    2. Press the button below, then Import passwords and pick that file.
    3. Delete the .csv file afterwards — it holds your passwords as plain text.

    Your passwords go straight into WolfWeb's password manager; WolfWeb's own code never reads them.
